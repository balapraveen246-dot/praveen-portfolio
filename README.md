# 🚀 Praveen — MERN Stack & Freelance Web Developer

A modern, premium personal portfolio built with **React, Vite, Tailwind CSS, and Framer Motion**. Designed with an elegant dark theme, refined gold accents, smooth animations, and a responsive layout to showcase my skills, projects, and freelance web development services.

🌐 **Live Portfolio:** https://praveen-portfolio-lovat.vercel.app/

---

## ✨ Features

- 🎨 Premium dark theme with gold accents
- 📱 Fully responsive design for mobile, tablet, and desktop
- 🎬 Smooth animations and interactive hover effects
- 👨‍💻 About section and technology skills showcase
- 💼 Seven project cards with live demo links where available
- 🛠️ Freelance web development services
- 💬 WhatsApp integration for project inquiries
- 📧 Email contact option
- 🧭 Responsive navigation with a mobile menu
- 🔍 SEO-friendly page metadata
- 🚀 Ready for deployment on Vercel
